# 🚗 Smart Car Marketplace & Price Prediction System

A comprehensive car marketplace and management platform developed using **C# .NET**, **Wins Forms**, **Machine Learning**, and **Artificial Intelligence**. The system provides dedicated **Admin**, **Employee**, and **User** panels for managing vehicle listings, customer interactions, and business operations. It also integrates a machine learning model for car price prediction and an AI-powered consultant to assist users with vehicle-related queries and purchasing decisions.

## ✨ Features

### 👨‍💼 Admin Panel
- Manage users and employees
- Approve and monitor car listings
- View sales and system analytics
- Manage platform records and reports

### 👨‍🔧 Employee Panel
- Handle customer requests
- Verify vehicle information
- Manage inventory and listings
- Assist with operational tasks

### 👤 User Panel
- Browse available vehicles
- Search and filter car listings
- Submit vehicle information
- Receive AI-powered recommendations

### 🤖 AI & Machine Learning Integration
- Car Price Prediction using Machine Learning
- AI Consultant for vehicle recommendations
- Intelligent analysis based on vehicle features
- Data-driven decision support for buyers and sellers

## 🛠️ Technologies Used

- C# .NET
- Windows Forms
- Google Forms
- Postgres  SQL
- Machine Learning
- Artificial Intelligence
- Data Analytics

## 🔄 System Workflow

1. User submits or views vehicle information.
2. Vehicle data is stored and managed through the system.
3. Machine Learning model analyzes vehicle attributes and predicts market price.
4. AI Consultant provides recommendations and guidance.
5. Admin and Employees manage records, users, and listings through dedicated dashboards.

- Automate vehicle management processes.
- Provide accurate car price estimation using Machine Learning.
- Improve user experience through AI-powered assistance.
- Create a centralized platform for administrators, employees, and customers.
